# EtherMusic: Технический обзор проекта

## 1. Концепция и архитектура

**EtherMusic** — это веб-приложение, созданное как "нейро-медитативный звуковой процессор". Цель проекта — предоставить пользователю интуитивный инструмент для создания эмбиент-музыки и медитативных звуковых ландшафтов без необходимости в музыкальном образовании.

Приложение построено на современном технологическом стеке, обеспечивающем высокую производительность, интерактивность и качественный звук в браузере.

### Технологический стек:

*   **Фреймворк:** Next.js (React) с App Router.
*   **UI:** ShadCN UI (компоненты на базе Radix UI) и Tailwind CSS для стилизации.
*   **Звуковой движок:** Tone.js — основная библиотека для синтеза и обработки звука в реальном времени.
*   **Язык:** TypeScript для строгой типизации и улучшения качества кода.
*   **Асинхронные вычисления:** Web Workers для выноса генерации музыки из основного потока.

## 2. Глоссарий Studio Mixer (Каналы управления)

Для управления «виртуальным ансамблем» используется 9-канальный микшер. Вот расшифровка ключевых ролей:

*   **MST (Master):** Финальная шина микса перед лимитером.
*   **BASS (Bass):** Фундамент. Нижний порог ограничен MIDI 31 (G1) для предотвращения гула.
*   **LEAD (Melody):** Солирующий голос (Гитара, Тераменвокс, Синтезатор).
*   **KEYB (Accompaniment):** "Keyboards". Канал для пэдов и органов. Создает гармоническую подложку (Pads/Clouds). Подключен к Sidechain от бочки.
*   **PIANO (Piano Accompaniment):** Специальный канал для Rhodes или акустического пианино. Работает независимо от пэдов.
*   **RTM (Harmony):** "Rhythm/Harmony". Второстепенная гармония. В блюзе — аккордовая гитара, в амбиенте — скрипичные акценты.
*   **SP (Sparkles):** "Искры". Текстурная микро-перкуссия и "звуковая пыль". Нетональные атмосферные звуки.
*   **SFX (Sound Effects):** Звуковые спецэффекты (голоса роботов, лазеры, виниловый треск).
*   **DRM (Drums):** Вся ударная установка.

## 3. Эволюция звукового движка: Квест за чистым звуком

Архитектура звукового движка — это сердце приложения. Она прошла несколько этапов эволюции в борьбе за производительность и чистоту звука, особенно на мобильных устройствах.

### Акт 1: Иллюзия простоты и ловушка `PolySynth`
Изначально использовался `PolySynth`, но он создавал огромную нагрузку на CPU, вызывая хрипы на мобильных устройствах.

### Акт 2: Армия моносинтезаторов в пуле
Мы перешли на пул независимых `Tone.Synth`. Это позволило контролировать каждый голос отдельно и полностью устранило артефакты синтеза.

### Акт 3: Изоляция через Web Worker
Вся логика "сочинения" вынесена в отдельный поток. Основной поток только исполняет команды, что делает UI на 100% отзывчивым.

## 4. Логика автоматизации пресетов (Mixer Presets)

Система микширования поддерживает интеллектуальное управление балансом:

*   **Capture (Запомнить):** Создает мгновенный снимок всех фейдеров и сохраняет его под новым именем в `localStorage`.
*   **Update (Обновить):** Перезаписывает значения активного пресета текущими настройками микшера.
*   **Mapping (Жанровая привязка):** Выбор жанра в дропдауне пресета привязывает его к музыкальному контексту. При смене жанра в Маршруте (Route), система автоматически загружает соответствующий пресет.
*   **Reset (Сброс):** Возвращает систему к "Золотому балансу" (дефолтные значения из `master-mix.ts`), отключая пользовательские надстройки.

## 5. Новые возможности (v1.1.0)

*   **Full Track Record (FTR):** Автоматизированная запись одной полной сюиты (160 тактов) с последующей авто-паузой.
*   **Direct Stream Bridge:** Режим трансляции для стабильной фоновой работы на мобильных устройствах.
