# Реестр ударных и перкуссии: Ambient Domain (v1.0)

Этот документ содержит полный список сэмплов, используемых генеративным движком `AmbientBrain` для создания атмосферных ландшафтов.

---

## 1. Фундаментальные звуки (Core Drums)
*Эти звуки создают редкий, но глубокий ритмический скелет.*

| ID Сэмпла | Путь к файлу | Описание |
|:----------|:-------------|:---------|
| **drum_kick_soft** | `/assets/drums/kick_soft.ogg` | Глухой, мягкий удар бочки. |
| **drum_kick_reso** | `/assets/drums/drum_kick_reso.ogg` | Резонирующий низкочастотный кик. |
| **drum_snare_ghost** | `/assets/drums/snare_ghost_note.ogg` | Едва уловимый шелест малого барабана. |
| **drum_snare_off** | `/assets/drums/snare_off.ogg` | Сухой удар без резонанса (для Dark). |
| **drum_brush1** | `/assets/drums/brush1.ogg` | Хэт, сыгранный щетками (для Calm). |
| **drum_hat_ghost** | `/assets/drums/closed_hi_hat_ghost.ogg` | Призрачный закрытый хэт. |

---

## 2. Атмосферные тарелки (Ethereal Rides)
*Создают «воздух» и длинные затухающие хвосты.*

*   **Ride Wetter**: `/assets/drums/ride_wetter.ogg` — Максимально «мокрый» райд.
*   **A-Ride 1**: `/assets/drums/a-ride2.ogg` — Глубокий гонг-эффект (для Dark).

## 4. Резонансные трубки и Бонго (The Tubes)
*Основа «Психоделической кухни».*

*   **PVC Tubes**: `/assets/drums/bongo/pvc-tube-01.ogg` по `03.ogg` — Глухие пластиковые удары.
*   **PC Bongos**: `/assets/drums/bongo/pc-01.ogg` по `03.ogg` — Короткие перкуссионные щелчки.

---

## 5. Текстурная перкуссия (Atmospheric Hits)
*Полный набор `perc-001` - `perc-015`.*

*   **Локация**: `/assets/drums/perc-[001-015].ogg`
*   **Применение**: Рассыпаются случайным образом по панораме с пониженной громкостью, создавая эффект присутствия в живом пространстве.
