# Руководство по Media Session API: Победа над системными плеерами

Этот документ описывает опыт борьбы за стабильное отображение метаданных и работу системных кнопок управления в приложении AuraGroove, особенно в ОС Linux Mint 22 (Cinnamon) и Chrome ОС.

---

## 1. Проблематика (Почему это не работало)

1.  **Кража фокуса (Session Stealing)**: При включении режима "Радио" (Broadcast Bridge) создается скрытый элемент `<audio>`. Браузер считает его новым источником звука. Если у него нет своих метаданных, он перехватывает "фокус" медиа-сессии у основного приложения, и ОС видит "Анонимный источник: Остановлено".
2.  **Дрейф времени**: Если аудио-поток (как в нашем случае) не имеет фиксированной длительности, ОС часто считает его "коротким звуком" и отключает виджет через 2-3 секунды после старта.
3.  **Относительные пути**: Системные мосты (MPRIS в Linux) часто не могут разрешить пути вида `/assets/cover.jpg`. Им нужны полные URL с указанием домена.
4.  **Игнорирование тишины**: Браузеры (Chromium) часто игнорируют элементы с атрибутом `muted`, не создавая для них медиа-сессию.

---

## 2. Золотой стандарт конфигурации (Рецепт победы)

Чтобы Media Session API работал стабильно с первого раза, нужно выполнить следующие 5 условий:

### А. Принудительное "Сердцебиение" (Heartbeat)
Нельзя полагаться на то, что браузер один раз запомнит данные. Нужно создать цикл (раз в 2 секунды), который принудительно перезаписывает `navigator.mediaSession.metadata` и `playbackState`. Это защищает сессию от перехвата другими элементами на странице.

### Б. Фиктивная позиция (Position State)
Даже для бесконечного генеративного потока нужно устанавливать `setPositionState`:
- Установите большую длительность (например, 3600 сек).
- Обновляйте текущую позицию на основе реального времени с момента нажатия Play.
- Это заставляет ОС считать, что "лента крутится", и убирает статус "Stopped".

### В. Изоляция побочных элементов
Элементы, созданные для технических нужд (как радиомост), должны быть:
- Без атрибута `muted` (используйте `volume = 0.01` на старте).
- Без собственных заголовков (`title`, `label`), чтобы не претендовать на роль главного плеера.
- С установленным `srcObject` до начала вызова метаданных.

### Г. Абсолютные пути к обложкам
Всегда используйте `window.location.origin` для формирования путей к изображениям. Добавляйте `query string` (например, `?v=123`), чтобы ОС не кэшировала пустую картинку.

### Д. Явное связывание действий (Action Handlers)
Обязательно регистрируйте обработчики для:
- `play`
- `pause`
- `stop`
- `nexttrack`
- `previoustrack`
Даже если `next` и `prev` просто сбрасывают текущий трек — их наличие в системе дает приложению статус "Полноценный плеер".

---

## 3. Чек-лист для разработчика

1. [ ] Файл обложки лежит в `public/assets/cover.jpg`.
2. [ ] В приложении есть `useEffect`, следящий за состоянием `isPlaying`.
3. [ ] Внутри этого эффекта запущен интервал `setInterval` (2 сек).
4. [ ] Метаданные передают массив `artwork` с размерами от 96x96 до 512x512.
5. [ ] Фоновые аудио-элементы имеют громкость 0.01 вместо Mute.

---
*Статус: Проверено на Linux Mint 22, Windows 11, Android 14.*
