# Руководство по Media Session API: Победа над системными плеерами (v2.0 Final)

Этот документ описывает финальный, эталонный метод интеграции AuraGroove с системными виджетами управления медиа.

---

## 1. Расположение ресурсов (Assets)

Для корректного отображения обложки на всех типах устройств, файлы должны располагаться строго в:
`public/assets/cover/`

**Обязательные размеры (JPG):**
- `cover96.jpg` (96x96)
- `cover128.jpg` (128x128)
- `cover192.jpg` (192x192)
- `cover256.jpg` (256x256)
- `cover512.jpg` (512x512)

---

## 2. Скрипт интеграции (useAuraGroove Hook)

Основная логика сосредоточена в `useEffect`, который срабатывает при изменении состояния `isPlaying`, `genre` или `mood`.

### А. Метаданные (MediaMetadata)
Мы используем объект `MediaMetadata`, транслируя:
- **Title**: `${genre.toUpperCase()} / ${mood.toUpperCase()}`
- **Artist**: 'AuraGroove'
- **Album**: 'The Infinite Take Band'
- **Artwork**: Массив объектов со ссылками на все размеры. К ссылкам прикрепляется `?v=${Date.now()}` для сброса системного кэша при смене атмосферы.

### Б. Визуализация бесконечности (Position State)
Генеративный поток не имеет конца. Чтобы ОС не писала «Остановлено», мы используем `setPositionState`:
- `duration: 7200` (фиктивные 2 часа).
- `position`: рассчитывается как время с момента старта сессии.
- Это создает эффект «крутящейся ленты» в виджете.

### В. Обработчики действий (Action Handlers)
Для получения статуса «Полноценный плеер» регистрируются обработчики:
- `play` / `pause`: управление воспроизведением.
- `stop`: полная очистка звуков.
- `nexttrack`: принудительная регенерация сюиты (новый Seed).
- `previoustrack`: перезапуск текущего воркера.

### Г. Сердцебиение (Heartbeat Loop)
Браузеры часто «забывают» метаданные при длительной игре. Внедрен `setInterval(updateMetadata, 2000)`, который каждые 2 секунды подтверждает системе, что AuraGroove всё еще является активным медиа-источником.

---

## 3. Синергия с Broadcast Bridge

**Файл:** `src/lib/broadcast-engine.ts`

**Критический хак:** 
Для того чтобы Chromium-браузеры не игнорировали аудио-элемент, он запускается с `volume = 0.01` вместо 0. Это позволяет Media Session API «зацепиться» за поток и вывести управление в системный трей.

---
*Статус: Стандарт утвержден. Проверено на Windows 11, Android 14, iOS 17.*
