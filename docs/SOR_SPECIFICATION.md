
# Техническая Спецификация: СОР (Система Обеспечения Разнообразия) v2.80

## 1. Концепция
СОР — это многоуровневая когнитивная надстройка над FractalMusicEngine, превращающая алгоритмическую генерацию в осмысленное музыкальное повествование. Система имитирует работу живого ансамбля, где каждый участник обладает памятью, слышит коллег и подчиняется драматическому сюжету.

---

## 2. Архитектура логики сбивок (The Shadow Drummer)

Логика филлов реализована как многоуровневый фильтр, работающий в фоновом потоке.

### 2.1. Схема взаимодействия компонентов

```text
[ WORKER DOMAIN ]
       |
[ ambient.worker.ts ] ──> Вызывает ShadowDrummer.decorate()
       |
       v
[ src/lib/assets/drum-fill-registry.ts ] <── (БИБЛИОТЕКА ПАТТЕРНОВ)
       |
       ├─ Class: ShadowDrummer (Теневой Дирижер)
       │    └─ Method: decorate() ──> [ АЛГОРИТМ ПРИНЯТИЯ РЕШЕНИЙ ]
       │         ├─ 1. Melody Guard (Проверка наложения на соло)
       │         ├─ 2. Pickup Logic (Вставка Snare на 11-м тике)
       │         ├─ 3. Pattern Selection (Выбор из FILL_PATTERNS)
       │         └─ 4. Landing Logic (Вставка Crash на 0-м тике)
       |
[ SCORE_READY ] ──> Передача массива FractalEvent[] в UI-поток
       |
       v
[ UI / AUDIO DOMAIN ]
       |
[ src/lib/drum-machine.ts ]
       |
       └─ Class: DrumMachine
            └─ Method: schedule() ──> [ ТРИГГЕР СЭМПЛОВ .OGG ]
```

## 3. Ключевые Технологии v2.80 (TOTAL STABILIZATION)

### 3.1. Call & Response Protocol (Слух Барабанщика)
*   **Mechanism**: Динамический анализ массива `FractalEvent[]` перед планированием сбивки.
*   **Melody Guard (Standard)**: Если плотность нот в слое `melody` на отрезке [6-11 тиков] превышает порог 0.2, сбивка `drums` переносится на следующий цикл.
*   **Melody Guard (Trance/Foundry Bypass)**: Для нагруженных жанров «Заслон Мелодии» отключен для создания эффекта «стены звука». Сбивки происходят каждые 4 такта.
*   **Result**: Ударные идеально адаптируются к жанровой специфике.

### 3.2. Hard Golden Filter (Физическая Оптимизация)
*   **Target**: Жанры Trance и Foundry при плотности > 3 нот/такт.
*   **Logic**: Принудительное удаление всех событий (melody, accomp, piano), не попадающих в сетку [0, 3, 6, 9]. 
*   **Result**: Сокращение количества создаваемых AudioNodes на 50% без потери ритмической структуры.

### 3.3. Ensemble Pulse (Ритмический Вдох)
*   **Pickup Logic**: Генерация одиночного удара Snare на 11-м тике такта, предшествующего филлу.
*   **Landing Logic**: Принудительная вставка события Crash на 0-й тик такта, следующего за филлом.
*   **Result**: Полное устранение ощущения "пустоты" и пауз в ритм-секции при переходах.
