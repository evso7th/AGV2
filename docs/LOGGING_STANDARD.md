# Стандарт Когнитивного Логирования AuraGroove (v1.1)

Этот документ определяет структуру и наполнение системных логов в консоли. Логи в AuraGroove являются «окном в мозг» музыкального интеллекта и должны быть максимально информативны для человека.

---

## 1. Структура основного тактового лога (Bar Log)

Каждый такт (Bar) в консоль выводится блок данных следующего формата:

```text
[HH:MM:SS] [Bar N] [PART_NAME] [DNA: Composition_Name] T:0.XX B:0.XX Axioms: [MEL: ID] [BASS: ID] ...
  ↳ Narrative: Краткое описание музыкального смысла (например: "Aching call with high vibrato")
  | Timbres: [MEL: Instrument_Name] [BASS: Instrument_Name] ...
```

### Поля лога:
*   **[Bar N]**: Текущий такт сюиты (0-159).
*   **[PART_NAME]**: Секция Блюпринта (INTRO, MAIN, BRIDGE и т.д.).
*   **[DNA]**: Имя текущего трека-донора из Наследия. Если играет алгоритм — пишется "Generative".
*   **T (Tension)**: Уровень напряжения (0.1 - 0.95).
*   **B (Beauty)**: Оценка гармонического резонанса Арбитром.
*   **Axioms**: Список ID активных аксиом для каждого канала.
*   **Narrative**: Поле из базы данных, объясняющее «душу» этого фрагмента.

## 2. Визуальный стиль

Логи используют CSS-стилизацию для быстрого считывания:
*   **Серый (#888)**: Служебная информация и заголовки.
*   **Фиолетовый (#c084fc)**: Поле Narrative (самое важное для понимания контекста).
*   **Жирный шрифт**: Ключевые параметры (Tension, Bar).

## 3. Событийные логи

*   **[Chronos]**: Маркирует смену Сюиты или запуск «Протокола Винилового Перехода».
*   **[Mapping]**: Указывает на успешный подбор Блюпринта под Genre/Mood.
*   **[Calibration]**: Отражает применение системных гейнов к сэмплерам.
