
# EtherMusic: Технический обзор проекта

## 1. Концепция и архитектура

**EtherMusic** (AuraGroove V3) — это веб-приложение, созданное как "нейро-медитативный звуковой процессор". Цель проекта — предоставить пользователю интуитивный инструмент для создания эмбиент-музыки и медитативных звуковых ландшафтов без необходимости в музыкальном образовании.

Приложение построено на современном технологическом стеке, обеспечивающем высокую производительность, интерактивность и качественный звук в браузере.

### Технологический стек:

*   **Фреймворк:** Next.js (React) с App Router.
*   **UI:** ShadCN UI (компоненты на базе Radix UI) и Tailwind CSS для стилизации.
*   **Звуковой движок:** Tone.js и Native Web Audio API — основная библиотека для синтеза и обработки звука в реальном времени.
*   **Асинхронные вычисления:** Web Workers для выноса генерации музыки из основного потока.
*   **Автономность:** IndexedDB (idb) для кэширования аудио-ассетов и ДНК Наследия.

## 2. Глоссарий Studio Mixer (Каналы управления)

Для управления «виртуальным ансамблем» используется 9-канальный микшер:

*   **MST (Master):** Финальная шина микса перед лимитером (-6dB).
*   **BASS (Bass):** Фундамент. Нижний порог ограничен MIDI 31 (G1) для предотвращения гула.
*   **LEAD (Melody):** Солирующий голос. Ограничен MIDI 71 («Вельветовый Стандарт»).
*   **KEYB (Accompaniment):** Пэды и органы. Подключен к Sidechain от бочки.
*   **PIANO (Piano Accompaniment):** Канал для Rhodes или акустического пианино.
*   **RTM (Harmony):** Второстепенная гармония. Гитарные аккорды или скрипичные акценты.
*   **SP (Sparkles):** Текстурная микро-перкуссия и "звуковая пыль".
*   **SFX (Sound Effects):** Звуковые спецэффекты (голоса роботов, лазеры, виниловый треск).
*   **DRM (Drums):** Вся ударная установка.

## 3. Ключевые Протоколы (v3.7.1)

### 3.1. Протокол Проактивного Баланса
Система применяет настройки микшера и тембры мгновенно при нажатии кнопки Play, анализируя первый элемент очереди. Это устраняет задержку («холодный старт») и гарантирует верное звучание с первой миллисекунды.

### 3.2. Протокол Мягкого Входа (Soft Entrance)
Линейное нарастание громкости (множитель 0.3 -> 1.0) для каналов Melody, Piano и Accompaniment в течение первых 6 тактов каждой композиции. Обеспечивает плавное вступление инструментов.

### 3.3. Вельветовый Стандарт (Velvet Standard)
Мелодический заслон на уровне MIDI 71. Все ноты выше этого порога принудительно переносятся октавой ниже, что создает плотный, теплый и комфортный тембральный профиль.

## 4. Логика автоматизации пресетов (Mixer Presets)

Система микширования поддерживает интеллектуальное управление балансом:

*   **Capture (Запомнить):** Создает мгновенный снимок всех фейдеров и сохраняет его в `localStorage`.
*   **Mapping (Жанровая привязка):** Выбор жанра в дропдауне пресета привязывает его к музыкальному контексту.
*   **Reset (Сброс):** Возвращает систему к "Золотому балансу" (дефолтные значения из манифеста `mixer-seeds.json`).

## 5. Новые возможности (v1.1.0)

*   **Full Track Record (FTR):** Автоматизированная запись одной полной сюиты (160 тактов) с последующей авто-паузой.
*   **Masterforge Vault:** Система 100% оффлайн-синхронизации всех ассетов и DNA.
