AuraGroove V 0.4.50: Полное руководство пользователя

1. Что такое AuraGroove?

AuraGroove — это автономный музыкальный интеллект, создающий уникальную фоновую музыку в реальном времени. Наша система не является нейросетью и не работает с текстовыми промптами. Это математический генератор: каждая нота рождается из сложного взаимодействия фрактальных алгоритмов и генетической памяти прямо на вашем устройстве.

2. Персональный Sound Check

Каждое устройство и наушники звучат по-разному. Чтобы получить наилучшие впечатления, откалибруйте звук под себя (это нужно сделать только один раз):

  • Нажмите кнопку Play.
  • Откройте Grand Studio Console (иконка слайдеров).
  • Настройте громкость каждой партии (Бас, Лид, Клавиши) до идеального баланса.
  • Используйте EQ для усиления или ослабления частот под вашу акустику.

3. Управление Пресетами

Пресеты позволяют мгновенно возвращать любимые настройки. После калибровки микшера введите имя пресета в навигаторе и нажмите "Save". Ваши настройки сохраняются локально в браузере.

4. Привязка Пресета к Жанру

Для разных стилей нужны разные настройки (например, в Reggae нужен более громкий бас). Выберите жанр рядом с именем сохраненного пресета, и система сама будет включать его при смене жанра в Маршруте.

5. Основные Кнопки

  • Play/Pause: Старт и остановка воспроизведения.
  • Regenerate: Если музыка не нравится, нажмите эту кнопку для создания абсолютно новой идеи с новым "Семенем".
  • Like: Сохраняет ДНК текущей пьесы в облачный реестр шедевров для улучшения будущих генераций.

6. Режимы Записи

Manual: Записывает фрагмент в .webm файл. Full Track Record (FTR): Записывает целую пьесу (160 тактов) от начала до конца и сама останавливается.

7. Broadcast Bridge

Специальный режим для работы на слабых устройствах. Позволяет транслировать звук с мощного ПК на телефон без задержек и заиканий, используя локальную сеть.

8. Создание Маршрута (Journey)

Выберите Жанр и Настроение, затем нажмите "Add to Route". Соберите свою цепочку настроений, перемешивайте их или сохраняйте целые «путешествия» в библиотеку.

9. Наследие (Heritage) и Анкор

Heritage позволяет новой музыке наследовать удачные черты из «генофонда» шедевров. Анкор позволяет зафиксировать один трек как единственный генетический источник.

10. Лимит Голосов (ARP)

Настройка баланса между качеством и производительностью. Для ПК рекомендуется 256-512 голосов, для мобильных — 50-120. Set via the chip icon.

11. Приватность

Полное отсутствие сбора данных. Никакой телеметрии, профилей или слежки. Ваша музыка — только ваша.
