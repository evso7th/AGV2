How Music is Born in AuraGroove

The entire process, from a single number to a rich musical tapestry, is deterministic. This means the same initial "seed" will always produce the exact same musical journey.

1Seed: The Source of Harmony

It all starts with a single 32-bit number. This seed ensures that the same code always creates the exact same music. It initializes a pseudo-random generator, making the entire composition process reproducible.

2DNA: The Master Plan

Based on the Seed, a 160-bar plan is constructed: a harmony map (using Markov chains) and a Tension Map, which dictates the ebb and flow of musical energy for the entire piece.

3Brain: Genre Intelligence

Specialized modules (BluesBrain, AmbientBrain) "compose" music for each bar using chord context, the required tension level, and selected axioms from the Heritage library.

4Fractals: Mutations

Axioms from the database are not static files but "musical clay". The Brain applies mathematical filters—inversion, retrograde, and rhythmic jitter—turning short phrases into an endless, living flow of variations.

5Audio: Materialization

Final commands are sent to the audio engine. Every note is synthesized or triggered as a sample via the Web Audio API directly on your device, creating a live and immersive soundscape.
