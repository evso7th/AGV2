### ЗАПИСЬ: 2026-06-21 (Проактивный look-ahead буфер планирования — отложено)

**ID:** `FEAT-SCHEDULER-LOOKAHEAD`
**Статус:** Обсуждено, отложено. Вернуться после проверки текущего фикса тайминга.

**КОНТЕКСТ**: Варны `[MelodySynthManagerV2] barStartTime in past` — рассинхрон допусков: движок перепланировал такт только при опоздании >100 мс, а менеджеры роняют такт при любом опоздании. Зазор 0–100 мс ронял такты (слышимые дыры). **Текущий фикс** (`audio-engine-context.tsx` SCORE_READY): перепланировать, если `scheduleTime < now + 0.03` → `now + 0.15`. Снимает симптом.

**ИДЕЯ**: Проактивный look-ahead — планировать следующий такт заранее (пока играет текущий), держа 1-2 такта (~1.5-3 с) запланированными, а не латать границу. Канонический способ убрать джиттер-рассинхрон (после планирования Web Audio играет сэмпл-точно).

**РЕШЕНО по объёму**: НЕ 3-4 с, а **1-2 такта**. Причина — два ограничения:
*   Лаг реакции на управление (жанр/настроение/инструмент/regenerate) — пользователь сказал НЕсущественно.
*   **КРИТИЧНО — раздувание голосов**: в этом движке аудио-узлы (осцилляторы/сэмпл-источники) создаются в момент ПЛАНИРОВАНИЯ, а не воспроизведения, и сразу попадают в реестр голосов (лимит 512). Глубокий буфер = кратно больше одновременно живых узлов → CPU + давление на voice-stealing (конфликт с недавно чинённым GC-штормом).

**ЧИСТОЕ РЕШЕНИЕ на 3-4 с** (если когда-нибудь): разделить «генерацию событий» (можно вперёд) и «создание аудио-узлов» (только just-in-time). Это заметный рефактор тайминга. Для 1-2 тактов можно обойтись без него (умеренное раздувание приемлемо).

### ЗАПИСЬ: 2026-06-21 (Пайплайн мастерписов в генерацию — НЕ ДОДЕЛАНО)

**ID:** `FEAT-MASTERPIECES-PIPELINE`
**Статус:** Известный пробел. Требуется для gap-fillers и «кирпичиков» при выключенном Наследии.

**ПРОБЛЕМА**: Движок ЧИТАЕТ `config.masterpieces` (передаётся в `generateSuiteDNA`, `fractal-music-engine.ts:143`, под гейтом `useHeritage`), но **никто его не заполняет**:
*   В воркере (`app/ambient.worker.ts`) передаётся только `cloudAxioms` (команда `update_cloud_axioms`); команды `update_masterpieces` нет.
*   Коллекция Firestore `masterpieces` нигде не загружается для генерации (есть только запись `saveMasterpiece`). В `use-aura-groove` слова `masterpieces` нет.
*   Итог: `generateSuiteDNA` получает `undefined` → мастерписы в генерации сейчас НЕ участвуют.

**ЧТО НУЖНО**: По образцу `refreshCloudAxioms` (`audio-engine-context.tsx:303`): загрузить коллекцию `masterpieces` → отправить воркеру новой командой → выставить `config.masterpieces`.

**ЗАЧЕМ**:
*   **gap-fillers** — заполнять музыкой длинные паузы в аксиомах (отдельная задача позже).
*   **Кирпичики при Наследии-off** — мастерписы как материал генерации.

**СВЯЗЬ С АВТОНОМНОСТЬЮ**: Когда мастерписы станут generation input, локальный кэш (IndexedDB, stale-while-revalidate) должен включать и `masterpieces` (3.73 МБ аксиом + размер мастерписов). Коллекция общая и растёт через Likes всех пользователей → нужен фоновый ресинк, не замороженный снапшот.

### ЗАПИСЬ: 2026-06-21 (Калибровка громкости гитар — дев-инструменты)

**ID:** `TOOL-CALIB-001`
**Статус:** Реализовано и оставлено в коде (НЕ удалять — пригодится для перекалибровки).

**ЧТО ЭТО**: Дев-инструмент офлайн-замера громкости гитар (Option A).

*   **`src/app/calibrate/page.tsx`** — дев-страница `/calibrate`. Кнопка «Run Calibration» → таблица RMS и трим-дБ (vs telecaster). НЕ для прода, только для разработки.
*   **`src/lib/guitar-loudness-calibration.ts`** — логика замера: офлайн-рендер (`OfflineAudioContext`) каждой гитары на референс-ноте A3/vel0.8, RMS в окне 0.55–0.80 c, трим = разница с telecaster.

**ЗАЧЕМ БЫЛИ НУЖНЫ**: выровнять воспринимаемую громкость всех гитар под единый референс (telecaster). «Подкрутить ручки» не работает — у сэмплеров своя громкость запечена в файлах, а preamp стоит ДО дисторшна (меняет тембр, не уровень).

**КУДА ЛОЖАТСЯ РЕЗУЛЬТАТЫ**:
*   Сэмплеры (telecaster/darkTelecaster/black/cs80) → `GUITAR_LOUDNESS_TRIM_DB` в `src/lib/guitar-loudness.ts`, применяется через `setOutputTrim()` (пост-окрасочный gain в каждом сэмплере) в `audio-engine-context`.
*   Синт-гитары (guitar_shineOn/muffLead) → `calibrationTrimDb` в пресете (`presets-v2.ts`), пост-лимитерный трим в `buildMultiInstrument`.

**ВАЖНО при перекалибровке**: `ENGINE_PREAMP` в калибровочном модуле ДОЛЖЕН совпадать с `SAMPLER_DEFAULTS` × пользовательскими gains из `audio-engine-context` (иначе числа мимо). Замер сейчас по одной ноте A3 — при желании расширить до усреднения по нескольким нотам.
