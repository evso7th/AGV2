### ЗАПИСЬ: 2024-11-04 (ПЛАН №1258: Оптимизация GC в Фабрике)
**СОБЫТИЕ**: Реализован Этап 1 по ликвидации нагрузки на сборщик мусора.
**ИТОГ**:
1. **Wave Cache**: Внедрено кэширование `PeriodicWave` для гитар и органов. Тяжелые Web Audio объекты больше не создаются на каждую ноту.
2. **Curve Cache**: Кривые для `WaveShaper` (Muff/SoftDrive) теперь вычисляются один раз и переиспользуются.
3. **Memory Stability**: Прекращена аллокация тысяч массивов `Float32Array` в секунду, что должно устранить "затыки" при 1024 голосах.
