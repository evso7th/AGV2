
# Журнал Проекта "AuraGroove"

---

### ЗАПИСЬ: 16-03-2026 (ПЛАН №33: DEVICE-SPECIFIC POLYPHONY DEFAULTS)
**СОБЫТИЕ**: Оптимизация лимитов полифонии под тип устройства.
**ПРИЧИНА**: Потребность в автоматической настройке производительности.
**ИЗМЕНЕНИЯ**:
1. **Capacity Logic**: В `AudioEngineProvider` обновлен `useEffect` для определения типа устройства.
2. **Mobile Default**: Установлен лимит в **120** голосов для смартфонов и планшетов.
3. **PC Default**: Установлен лимит в **256** голосов для десктопных систем.
4. **Registry Sync**: Фабрика инструментов теперь по умолчанию инициализируется с лимитом 256.
**ИТОГ**: Приложение автоматически выбирает оптимальный режим работы, обеспечивая богатый звук на ПК и стабильность на мобильных устройствах.

### ЗАПИСЬ: 16-03-2026 (ПЛАН №32: POLYPHONY CONTROL & UI CLEANUP)
**СОБЫТИЕ**: Реорганизация ресурсов и упрощение футера Навигатора.
**ПРИЧИНА**: Запрос на удаление доступа к Expert Mode и возврат контроля над полифонией.
**ИЗМЕНЕНИЯ**:
1. **UI Clean**: Кнопка `Cog` (Expert Mode) удалена из футера Навигатора.
2. **Resource Control**: Возвращена кнопка `Layers` в футер с модальным окном управления лимитом голосов (`voiceLimit`).
3. **Telemetry**: В шапку Навигатора добавлен инфо-бэдж, отображающий текущий лимит голосов рядом с названием системы.
**ИТОГ**: Интерфейс стал чище, а контроль над нагрузку на устройство — доступнее.
