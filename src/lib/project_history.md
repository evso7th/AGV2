
# Журнал Проекта "AuraGroove"

---

### ЗАЧЕМ: ВОСКРЕШЕНИЕ НЕЙРОСПЕЙСА (Trance/Foundry Recovery)
**СОБЫТИЕ**: Устранение критических ошибок в `TranceBrain` и `DarkFoundryBrain`, вызывавших зависание на 1-м такте.
**РЕЗУЛЬТАТ**:
1. **Pool Guard Implementation**: Добавлены жесткие проверки `basePool.length > 0` перед доступом к массиву аксиом. Это предотвратило крах воркера при частичном несовпадении тегов.
2. **Reference Integrity**: Исправлены неверные обращения к `this.config.cloudAxioms` (заменено на `this.cloudAxioms`) и `this.random` (заменено на `this.rng`).
3. **Inclusive Genre Matching**: Воркер теперь понимает, что `psybient` (Neuro Space) и `foundry` (Dark Trance) являются легитимными потребителями аксиом с тегом `trance`.
4. **Const Scope Fix**: Переменные `filteredPool` во всех модулях окончательно переведены на `let` для обеспечения возможности переназначения при выборе "Якоря".
5. **Resurrection Complete**: Жанры Neuro Space и Dark Trance снова полностью функциональны.

---

### ЗАЧЕМ: ЗАКОН ВНУТРЕННЕЙ РОТАЦИИ (Lick Rotation Protocol)
**СОБЫТИЕ**: Внедрение интеллектуальной ротации аксиом внутри одного трека-донора.
**РЕЗУЛЬТАТ**:
1. Все «Мозги» (`Ambient`, `Blues`, `Trance`, `Reggae`, `Foundry`) теперь ведут сессионную историю сыгранных фрагментов (`lickHistory`).
2. При выборе следующей темы (`selectNextAxiom`) система отдает приоритет тем фрагментам, которые еще не звучали в текущей сессии.
3. **Ликвидация «Ловушки первого индекса»**: если идеальное совпадение по времени уже играло, ансамбль выбирает другую мелодию из этого же трека.
4. Повторное воспроизведение одного и того же трека-донора в рамках одной сессии теперь всегда звучит по-разному.

---

### ЗАЧЕМ: ПРОТОКОЛ "BASS PURITY" (Anti-Hum Strategy)
**СОБЫТИЕ**: Глубокая очистка низкочастотного спектра.
**РЕЗУЛЬТАТ**:
1. **Master HPF (35Hz)**: Внедрен фильтр на финальной шине для отсечки инфра-гула.
2. **DC-Cut (15Hz)**: Добавлен индивидуальный фильтр для каждого инструмента в фабрике.
3. **Mono Bass Mode**: Принудительная монофония баса с мгновенным затуханием предыдущей ноты.
4. **Sidechain Ducking**: Реализовано автоматическое приглушение баса при ударе бочки (Ducking до 20% громкости).
