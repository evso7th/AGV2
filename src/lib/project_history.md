
# Журнал Проекта "AuraGroove"

---

### ЗАЧЕМ: OFFLINE HARDENING (Resilient PWA & Vault)
**СОБЫТИЕ**: Глубокая модернизация системы автономности для предотвращения «протухания» кода и падений при старте.
**РЕЗУЛЬТАТ**:
1. **PWA Immortality**: В `next.config.js` стратегии для статического кода и аудио изменены на `CacheFirst` с TTL 60-90 дней. Устранена проблема блокировки запуска при отсутствии сети через 2-3 дня.
2. **Zero-Throw Vault**: Метод `vault.fetch` переведен на safe-mode (try/catch). Теперь отсутствие сетевого соединения или отдельного файла не вызывает крах инициализации.
3. **Graceful Init**: Процесс `initialize()` в AudioEngine переведен на `Promise.allSettled`, что гарантирует старт системы даже при частичной потере ассетов.
4. **Code Survival**: HTML-страницы теперь кэшируются по стратегии `CacheFirst` для предотвращения системных ошибок 404 при глубоком оффлайне.

---

### ЗАЧЕМ: SOURCE INTEL MODE (Cloud vs Local Toggle)
**СОБЫТИЕ**: Внедрение функции выбора источника генетического материала.
**РЕЗУЛЬТАТ**:
1. **Source Preference**: В `AudioEngineContext` добавлено состояние `dnaSourcePreference` ('cache' | 'network').
2. **Cloud-First Logic**: В режиме `network` система принудительно ожидает свежие Аксиомы и Шедевры из Firestore при старте.
3. **Vault-First Logic**: Режим по умолчанию гарантирует мгновенный оффлайн-старт из IndexedDB.
4. **UI Integration**: В окне Masterforge Vault добавлен переключатель для управления приоритетом.
5. **Persistence**: Выбор пользователя сохраняется в `localStorage`.

---

### ЗАЧЕМ: ETERNAL OFFLINE PROTOCOL (V2.0 Synchronization)
**СОБЫТИЕ**: Глубокая перестройка кэширования и инициализации для обеспечения 100% автономности на срок до 30 дней.
**РЕЗУЛЬТАТ**:
1. **TTL Expansion**: Срок жизни программного кода и манифестов в кэше Service Worker увеличен до 30 дней. Устранена проблема «протухания» кэша через 24 часа.
2. **App Warm-up**: В процесс синхронизации добавлен принудительный прогрев (fetch) всех страниц приложения. Теперь программные бандлы скачиваются вместе со звуками.
3. **Non-blocking DNA**: Инициализация движка больше не ждет ответа от Firestore. При отсутствии сети система мгновенно переходит на использование локальных Аксиом или чистого алгоритма.
4. **Auth Speedrun**: Порог оффлайн-байпаса авторизации снижен до 1000 мс для ускорения холодного старта.
5. **Manifest Persistence**: Восстановлена корректная связь с `manifest.json`, что обеспечивает приложению статус «Установлено» и защиту хранилища от очистки браузером.
6. **Genetic Pool Refresh Rule**: В документацию внесено требование периодической синхронизации для загрузки новых «Шедевров» (Masterpieces) из облака.
