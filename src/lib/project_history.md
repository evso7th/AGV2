### ЗАПИСЬ: 2024-11-01 (ПЛАН №111: STRICT HERITAGE FILTERING)
**СОБЫТИЕ**: Реформа отбора треков-доноров из Наследия.
**ИЗМЕНЕНИЯ**:
1. **Worker**: В `pickActiveAnchor` удален фильтр по `commonMood`. Теперь отбор ведется только по прямому совпадению `Genre` и `Mood`.
2. **Brains**: Во всех специализированных процессорах (`BluesBrain`, `AmbientBrain`, `TranceBrain`, `ReggaeBrain`) реализована строгая фильтрация аксиом.
**ИТОГ**: Система больше не смешивает «похожие» настроения. Если пользователь выбрал `Blues/Melancholic`, система играет только те треки, которые помечены именно этими тегами.
