### ЗАЧЕМ: ПЛАН №1985 — Foundry Atmosphere Integration
**СОБЫТИЕ**: Подключение эффектов (SFX и Sparkles) к жанру Foundry без изменения кода менеджеров.
**ИТОГ**:
1. В `DarkFoundryBrain` внедрен метод `renderAtmosphericEvents`, генерирующий текстурные события.
2. Использована «Прямая Адресация»: события SFX теперь содержат явный список категорий (`dark`, `voice`), что позволяет `SfxSynthManager` находить нужные сэмплы для Литейной без правок своего внутреннего словаря.
3. Обновлен блюпринт `dark.ts` для Foundry: активированы слои и заданы вероятности появления индустриальных звуков.
4. Синхронизирована логика Sparkles: теперь они вступают в игру в реальном времени с вероятностью 15% за такт.
