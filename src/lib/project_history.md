# Журнал Проекта "AuraGroove"

---

### ЗАЧЕМ: ПЛАН №2600 (Audio Architecture Trace)
**СОБЫТИЕ**: Проведен полный аудит узлов регулировки громкости сэмплерных гитар.
**ЧТО**: 
1. Создан документ `docs/GUITAR_VOLUME_TRACE.md`.
2. Выявлены 5 уровней усиления: Note, Preamp, Trim, Channel, Master.
3. Подтверждена корректность работы `setOutputTrim` для нормализации громкости разных физических моделей.
**РЕЗУЛЬТАТ**: Разработчик имеет карту управления гейном для тонкой настройки баланса и устранения искажений.

---

### ЗАЧЕМ: ПЛАН №2311 (Infinite Journey Loop Fix)
**СОБЫТИЕ**: Исправление бага с зависанием очереди на последнем треке.
**ЧТО**: 
1. **Stable State Listening**: Обработчик `onTransition` в хуке `useAuraGroove` теперь использует `useRef` для доступа к очереди и текущему индексу. Это гарантирует, что переход к первому треку (Index 0) срабатывает всегда, даже если React не успел обновить состояние.
2. **Directive Handshake**: Воркер теперь принудительно сбрасывает счетчик тактов (`barCount = 0`), если получает любые настройки в состоянии ожидания перехода.
**РЕЗУЛЬТАТ**: Очередь (Route) теперь работает как бесконечная лента, гарантированно возвращаясь к началу без пауз и зацикливаний старого фрагмента.
