
# Журнал Проекта "AuraGroove"

---

### ЗАЧЕМ: ПЛАН №89: IMPERIAL MIXING STANDARD
**СОБЫТИЕ**: Унификация настроек микшера для всех жанров и обеспечение персистентности пресетов.
**ПРИЧИНА**: Поиск пользователем "идеального баланса" и требование стабильности звуковой картины при смене стилей.
**ИЗМЕНЕНИЯ**:
1.  **Master Mix**: Файл `master-mix.ts` полностью переписан. Все жанры теперь используют единые значения (Bass: 0.70, Melody: 0.21, Acc: 0.40, Drums: 0.75 и т.д.).
2.  **Logic**: В `use-aura-groove.ts` функция `applyAutoMix` теперь игнорирует локальные переопределения в Блюпринтах, обеспечивая "неподвижность" микшера.
3.  **Persistence**: Добавлена логика автоматической загрузки последнего активного пресета микшера и эквалайзера при старте приложения, если они были сохранены в `localStorage`.
**ИТОГ**: Звуковая сцена стала предсказуемой и профессиональной. Пользовательские настройки теперь имеют абсолютный приоритет над жанровыми шаблонами.

---

### ЗАЧЕМ: ПЛАН №88: DYNAMIC PIANO GROUPS
**СОБЫТИЕ**: Добавление динамических групп для пианиста (Rhodes ↔ Piano).
**ПРИЧИНА**: Повышение экспрессивности аккомпанемента в зависимости от музыкального напряжения (Tension).
**ИЗМЕНЕНИЯ**:
1.  **Music Theory**: В `resolveSemanticTimbre` добавлена логика для `dyn_rhodes_piano` и `dyn_piano_rhodes`. При низком напряжении используется первый инструмент, при высоком (>0.6) — второй.
2.  **Dashboard**: Добавлена новая категория `⚡ Dynamic Piano` в список выбора инструментов DNA Auditor.
3.  **UI**: Обновлен словарь `displayNames` для корректного отображения групп в интерфейсе.
**ИТОГ**: Пианист теперь может динамически менять характер звука от теплого электропиано до звонкого акустического пианино в зависимости от кульминаций сюиты.
