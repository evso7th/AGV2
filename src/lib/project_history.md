
# Журнал Проекта "AuraGroove"

---

### ЗАПИСЬ: 10-03-2026 (PLAN №1270: DRAG & DROP ROUTE MASTERY)
**СОБЫТИЕ**: Внедрение возможности интерактивного перетаскивания строк в маршрутном листе.
**ИЗМЕНЕНИЯ**: 
1. В `package.json` добавлены библиотеки `@dnd-kit/core`, `@dnd-kit/sortable` и `@dnd-kit/utilities`.
2. В `use-aura-groove.ts` реализована функция `reorderRoute`, использующая `arrayMove` для безопасного обновления состояния маршрута.
3. В `AuraGrooveRoute.tsx` список маршрута обернут в `DndContext`. Каждая строка теперь является перемещаемым компонентом `SortableRouteItem` с иконкой `GripVertical`.
4. Настроены сенсоры: `TouchSensor` с задержкой 250мс позволяет избежать случайных срабатываний при обычном скролле, обеспечивая корректную работу "пальцем".
**ИТОГ**: Пользователь может свободно менять структуру своего музыкального путешествия простым перетаскиванием сцен.
