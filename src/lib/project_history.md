
# Журнал Проекта "AuraGroove"

---

### ЗАПИСЬ: 2024-11-04 (ПЛАН №1265: Протокол Экстренной Деактивации)
**СОБЫТИЕ**: Устранение критических утечек памяти и оптимизация полифонии.
**ИТОГ**:
1. **FIFO Limiter**: Реестр голосов `globalActiveVoices` переведен на `Set`. Лимитер теперь работает по принципу FIFO без сортировки, что убирает CPU-затыки при 1024 голосах.
2. **Instance-Safe Cleanup**: Внедрен `instanceId` для инструментов. Теперь удаление старого пэда очищает только его собственные голоса, не трогая новые.
3. **Rotation Speedup**: Период "жизни" старого инструмента в менеджерах сокращен до 8 секунд (был 15). Это предотвращает накопление неиспользуемых AudioNodes в графе.
4. **Hard Node Stop**: Все узлы теперь получают явную команду `stop()` в `deepCleanup`, предотвращая фоновое гудение в Web Audio API.
