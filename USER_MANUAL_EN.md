
# AuraGroove User Manual

**Document Version: 3.7.1**

## 1. Welcome to AuraGroove!

AuraGroove is not just a player; it's an autonomous musical intelligence that creates unique music in real time. Every note is born from mathematical models and genetic algorithms, simulating a live ensemble.

## 2. First Things First: Personal Sound Check

Every device and audio system sounds different. Calibrate the system once:
1. **Press "Play"** to start.
2. **Adjust the Mixer** in the Grand Studio Console.
3. **Save as a Preset**. Your settings are stored locally.

## 3. 100% Offline Autonomy (Masterforge Vault)

AuraGroove is designed to function entirely without an internet connection. Once synced, it becomes a stand-alone music station.
1. **Initiate Sync All**: Tap the lightning icon (Vault) and run a full synchronization.
2. **Code Warm-up**: As of v3.7.1, the system automatically caches the application code for all main pages along with the audio atoms. No manual "tab-clicking" is required.
3. **Periodic Sync**: While the system can operate autonomously for up to 30 days, we recommend performing a "Sync All" whenever you have a stable connection. This ensures your local genetic pool receives the latest "Masterpieces" — successful musical states added to the cloud by users worldwide.
4. **Persistence**: The synchronized app will remain functional for up to 30 days without a network connection.
5. **PWA Installation**: We strongly recommend using the "Add to Home Screen" feature. This ensures Chrome grants the app "Persistent Storage" status, protecting your cache from being cleared.

## 4. Key Features

* **Play/Pause**: Control the flow.
* **Regenerate**: Create a new Seed and a fresh musical mutation instantly.
* **Save Masterpiece (Like)**: Contribute to the global Heritage pool.
* **Full Track Record (FTR)**: Automatically record a complete 160-bar suite.
* **Broadcast Bridge**: Stream ready-made audio to low-end devices to save CPU.

## 5. Creating a Journey (Route)

Build your own sequence of genres and moods. The playback queue operates in an **infinite cycle**: upon reaching the last item, the engine automatically loops back to the beginning with a fresh generation seed.
