
# AuraGroove User Manual

**Document Version: 3.7.1**

## 1. Welcome to AuraGroove!

AuraGroove is not just a player; it's an autonomous musical intelligence that creates unique music in real time. Every note is born from mathematical models and genetic algorithms, simulating a live ensemble.

## 2. First Things First: Personal Sound Check

Every device and audio system sounds different. Calibrate the system once:
1. **Press "Play"** to start.
2. **Adjust the Mixer** in the Grand Studio Console (sliders icon).
3. **Save as a Preset**. Your settings are stored locally.

## 3. 100% Offline Autonomy (Masterforge Vault)

AuraGroove is designed to function entirely without an internet connection. Once synced, it becomes a stand-alone music station.
1. **Initiate Sync All**: Tap the lightning icon (Vault) and run a full synchronization.
2. **Code Warm-up**: The system automatically caches the application code for all main pages. No manual "tab-clicking" is required.
3. **Periodic Sync**: We recommend performing a "Sync All" whenever online to refresh your local "Masterpieces" collection with new snapshots from the global community.
4. **PWA Installation**: Use the "Add to Home Screen" feature. This ensures Chrome grants the app "Persistent Storage" status, protecting your cache.

## 4. Key Features

* **Play/Pause**: Control the flow.
* **Regenerate**: Create a new Seed and a fresh musical mutation instantly.
* **Save Masterpiece (Like)**: Contribute to the global Heritage pool.
* **Source Intel Mode**: Find the **"Cloud-First DNA"** toggle in the Vault menu to pull live data directly from the Cloud, bypassing local storage.
* **Full Track Record (FTR)**: Automatically record a complete 160-bar suite.

## 5. Creating a Journey (Route)

Build your own sequence of genres and moods. 
* **Add**: Pick a combination and tap "+ To Playlist".
* **Clear**: Use the trash icon button to wipe the entire sequence.
* **Infinite Loop**: The playback queue operates in a continuous cycle. Upon reaching the last item, it automatically loops back with a fresh seed.
* **Mobile UI**: On mobile devices, labels are shortened (SF, NS, CB, etc.) to ensure a perfect fit on small screens.
