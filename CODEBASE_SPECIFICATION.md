
# Спецификация кодовой базы: AuraGroove (Версия 3.8.0 - Total Stabilization)

**Версия документа:** 3.8.0
**Дата обновления:** 2026-07-15

## 1. Обзор высокого уровня

### 1.1. Концепция проекта
**AuraGroove** — это высокопроизводительный генеративный аудио-движок, оптимизированный для мгновенного старта на любых устройствах. Приложение использует принцип "Core First", загружая минимально необходимое ядро ассетов для начала проигрывания и подгружая детали в фоновом режиме. 

### 1.2. Жанровая экосистема
Система поддерживает пять фундаментальных режимов генерации:
1. **Ambient (Slow Fusion)**: Глубокие текстуры, "Атласы" и медленное развитие.
2. **Blues (Cafe's Blues)**: Выразительная импровизация, законы Call & Response.
3. **Trance (Neuro Space)**: Пульсирующая энергия, фрактальные ритмы и Tier-приоритизация.
4. **Foundry (Dark Trance)**: Индустриальный металл. Мощные дисторшн-пэды и разреженная гармоническая сетка.
5. **Reggae (Root Reggey)**: Законы Риддима и One-Drop грув.

## 2. Логика композиции: The Golden Grid & Hard Culling
В версии 3.8.0 внедрены протоколы экстремальной стабильности:
- **«Золотая Сеть» (Hard Filter)**: В высокоплотных жанрах (Trance, Foundry) ноты, не попадающие на сильные четверти (0, 3, 6, 9 тики), физически отфильтровываются в Worker, если плотность такта превышает 3 события.
- **«Вельветовый Стандарт»**: Принудительное ограничение мелодии 4-й октавой (MIDI 71) для обеспечения теплого и плотного звучания без резких ВЧ.

## 3. Звуковой Тракт и Управление

### 3.1. Grand Studio Console
Полноэкранный десктопный микшер, объединяющий системные преампы (калибровка) и канальные стрипы инструментов.
- **Lookahead 0.35s**: Расширенный буфер безопасности планирования для исключения заиканий аудио-потока.
- **Proactive Balance**: Мгновенное применение пресетов микшера до начала игры.
- **Soft Entrance**: Плавное вступление Melody/Piano/Accompaniment за 6 тактов.

### 3.2. Визуальная подсистема
- **Visual Quietude**: Удалена система ритмической пульсации для минимизации нагрузки на Main Thread.
- **Visual Throttle**: Все анимации и анализатор спектра ограничены частотой 30 FPS.

## 4. Технологический стек
- **Тайминг**: Native Web Audio API (Lookahead Expansion Protocol).
- **Синтез**: Native Web Audio API (V2 Engine).
- **Сэмплирование**: Custom Hybrid Samplers (Black Acoustic, Telecaster, CS80, Yamaha Chords).
- **База данных**: Firebase Firestore (Heritage Axioms + Masterpieces).
- **Offline**: Masterforge Vault (IndexedDB + App Code Warm-up).
