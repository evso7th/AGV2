
# Спецификация кодовой базы: AuraGroove (Версия 3.0 - Sonic Lazy Load)

**Версия документа:** 3.0
**Дата обновления:** 2026-03-09

## 1. Обзор высокого уровня

### 1.1. Концепция проекта
**AuraGroove** — это высокопроизводительный генеративный аудио-движок, оптимизированный для мгновенного старта на любых устройствах. Приложение использует принцип "Core First", загружая минимально необходимое ядро ассетов для начала проигрывания и подгружая детали в фоновом режиме.

### 1.2. Архитектура загрузки ресурсов (Hybrid Loading)
Система использует многоуровневую стратегию инициализации для минимизации начальной задержки:

- **Уровень 1: Минимальное Ядро (Ready-to-Play)**
  - **Drums**: Приоритетная загрузка только Blues Kit.
  - **Guitars**: Загрузка только первой RR-вариации (Round Robin) для каждой ноты.
  - **Textures (Sparkles/SFX)**: Лимит 3 случайных сэмпла на категорию.
  - **Инструменты**: Piano, Violin, Guitar Chords (основные слои).
  - **Результат**: Кнопка Play становится активной через 3-5 секунд.

- **Уровень 2: Фоновое Пополнение (Resource Replenishment)**
  - Запускается через 5 секунд после готовности Ядра.
  - Догружает все оставшиеся RR-вариации для Black Acoustic и Telecaster.
  - Загружает тяжелые синтезаторы (CS80) и полную библиотеку SFX/Sparkles.
  - Не блокирует основной аудио-поток и UI.

- **Уровень 3: Asset Elimination (Flute-Free)**
  - Инструмент Flute полностью исключен из сетевых запросов для экономии трафика.

## 2. Логика композиции: Ensemble Lottery

Движок AuraGroove имитирует живое вступление музыкантов через систему "Жеребьевки":
1. При старте новой сессии инструменты случайным образом делятся на пары.
2. Первая пара вступает на такте 0.
3. Вторая пара — на такте 3.
4. Остальные участники ансамбля активируются на такте 6.
Это обеспечивает уникальность каждого интро при сохранении структурной целостности.

## 3. Звуковой Тракт и Управление

### 3.1. Grand Studio Console
Полноэкранный десктопный микшер, объединяющий системные преампы (калибровка) и канальные стрипы инструментов (Volume + Preset Select). 
- **Bass Preamp**: MIDI 31-47 (G1 Standard).
- **Master Shield**: Лимитер настроен на -12dB для предотвращения клиппинга.

### 3.2. Melodic Tie (Legato Engine)
Интеллектуальный алгоритм в `music-theory.ts`, который автоматически объединяет последовательные ноты одной высоты в единые лирические линии, избавляя мелодию от "пулеметного" эффекта.

## 4. Технологический стек
- **Тайминг**: Tone.js (Transport only).
- **Синтез**: Native Web Audio API (V2 Engine).
- **Сэмплирование**: Custom Hybrid Samplers (Black Acoustic, Telecaster, CS80).
- **Композиция**: Web Worker (FractalMusicEngine + specialised Brains).
- **База данных**: Firebase Firestore (Heritage Axioms + Masterpieces + Project Documents).
