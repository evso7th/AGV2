
# Спецификация кодовой базы: AuraGroove (Версия 3.5 - Foundry Sovereign)

**Дата обновления:** 2026-06-21

## 1. Обзор высокого уровня

### 1.1. Концепция проекта
**AuraGroove** — это высокопроизводительный генеративный аудио-движок, оптимизированный для мгновенного старта на любых устройствах. Приложение использует принцип "Core First", загружая минимально необходимое ядро ассетов для начала проигрывания и подгружая детали в фоновом режиме.

### 1.2. Жанровая экосистема
Система поддерживает четыре фундаментальных режима генерации:
1. **Ambient**: Глубокие текстуры, "Атласы" и медленное развитие.
2. **Blues**: Выразительная импровизация, законы Call & Response.
3. **Trance**: Пульсирующая энергия, фрактальные ритмы и сайдчейн.
4. **Foundry (New)**: Индустриальный металл. Мощные дисторшн-пэды, грязные органы и разреженная гармоническая сетка.

## 3. Звуковой Тракт и Управление

### 3.1. Grand Studio Console
Полноэкранный десктопный микшер, объединяющий системные преампы (калибровка) и канальные стрипы инструментов.
- **Foundry Sub-Mix**: Изолированная линия с пониженным в 4 раза усилением для ударных.
- **Master Shield**: Лимитер настроен на -12dB для предотвращения клиппинга.

## 4. Технологический стек
- **Тайминг**: Tone.js (Transport only).
- **Синтез**: Native Web Audio API (V2 Engine).
- **Сэмплирование**: Custom Hybrid Samplers (Black Acoustic, Telecaster, CS80, Yamaha Chords).
- **Композиция**: Web Worker (FractalMusicEngine + специализированные Brains: Ambient, Blues, Trance, Reggae, **DarkFoundry**).
- **База данных**: Firebase Firestore (Heritage Axioms + Masterpieces + Project Documents).
